# Next Step

A free, private money plan for hospital staff in New Jersey. One step at a time: what to do this month, what comes next, and how to do it.

- Single static page (`index.html`), no build step, no accounts. Data stays in the viewer's browser.
- 2026 federal and New Jersey rules live in the `RULES` table at the top of the script. Update it each year.

Education, not individual financial advice.
